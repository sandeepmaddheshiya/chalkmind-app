# Chalkwise: AI Whiteboard

A smart whiteboard for teaching and learning, built with Flutter.

- Handwritten maths solving (answers written back in handwriting), smart shapes, graphs
- AI tutor: explain, hints, check my work, quizzes, flashcards, lesson plans, editable diagrams
- PDF import and annotation, with highlight-to-look-up meanings
- Works offline for drawing; boards autosave on the device

## Run

AI needs an OpenRouter API key, kept out of git:

```sh
cp dart_defines.example.json dart_defines.json   # then put your key in it
flutter run --dart-define-from-file=dart_defines.json
```

Release build for a phone/tablet (arm64):

```sh
flutter build apk --release --split-per-abi --target-platform android-arm64 \
  --dart-define-from-file=dart_defines.json
```
